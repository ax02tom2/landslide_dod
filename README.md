# 崩塌地形變異分析｜案件管理版

## 作業順序
1. **案件管理**：登入 → 建立/開啟案件。
2. **① 前處理｜裁切與縮小**：處理大型 DEM/DSM，將成果保存到目前案件。
3. **② 地形變異分析｜DoD**：讀取目前案件的 T1/T2，繪製實際崩塌、潛在滑動體、堆積區、穩定區、排除區與剖面線，執行 DoD、殘餘土體、剖面與匯出。
4. **案件儲存**：設定與圈繪會保存到案件；重新開啟同一案件即可繼續。

## 使用者與案件
- 使用 SQLite 保存帳號與案件資料。
- 每個案件都有自己的資料夾，使用者只能查詢自己的案件。
- 密碼使用 PBKDF2-SHA256 雜湊保存，不保存明碼。
- `DOD_DATA_DIR` 可指定持久化資料位置；未設定時使用 `.dod_data/`。

## 重要限制
若部署在 Streamlit Community Cloud，單機檔案與 SQLite 會受到雲端執行環境的持久性限制；正式多人上線建議下一階段把 SQLite/案件檔案改成 Supabase/PostgreSQL + 物件儲存。這一版先提供簡單、低依賴的案件管理架構，適合本機或單一持久化主機。

## 大檔流程
超大型 DEM 仍建議先使用 ① 前處理｜裁切與縮小，再進入 DoD 分析，以降低記憶體使用量。
