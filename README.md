# 崩塌地形變異分析 DoD — V4 完整版

這是一個以 Streamlit 建立的兩期 DEM/DSM 地形變異分析工具，適合進行 DoD（DEM of Difference）、崩塌／堆積量體、潛在滑動體內殘餘不穩定土體、剖面與結果匯出。

## 一、正式操作順序

### ① 前處理｜裁切與縮小

先處理大型 GeoTIFF：

1. 提供 T1（崩塌前）與 T2（崩塌後）DEM/DSM。
2. 在地圖畫矩形、輸入座標，或選擇全範圍。
3. 鎖定研究範圍。
4. 視資料大小決定 DEM 縮小倍率。
5. 分別裁切 T1、T2；正射影像可選。
6. 完成後，分析頁會自動使用前處理成果。

前處理採分塊讀寫，避免為了裁切而把整個大型 GeoTIFF 一次載入 RAM。

### ② 地形變異分析｜DoD

分析頁的基本流程：

1. 載入 T1、T2。
2. 設定降採樣倍率、NoData、兩期對位校正與 LoD。
3. DoD：`dz = T2 - T1`。
4. 在地圖上分開圈繪「實際崩塌範圍」與「潛在滑動體範圍」。
5. 查看 DoD 崩塌／堆積統計。
6. 需要時進入殘餘土體，選擇滑動面假設並按按鈕計算。
7. 需要時執行敏感度分析。
8. 建立剖面與匯出結果。

## 二、空間邏輯

### 分析範圍

由前處理裁切結果決定。DoD 先在整個有效分析區計算。

### 實際崩塌範圍 🔴

使用者圈繪「已經實際崩塌」的區域。它只控制實際崩塌事件的統計，不用來定義潛在滑動體。

### 潛在滑動體範圍 🟣

使用者圈繪完整可能滑動體，包含已崩塌與尚未崩塌但可能失穩的部分。它主要用於殘餘不穩定土體分析。

### 堆積區 🔵

可圈繪泥土、岩屑等堆積位置；若未圈繪，系統依目前程式邏輯以潛在滑動體以外的有效區域作為堆積統計區域。

## 三、DoD 基本判定

- `dz < -LoD`：侵蝕／崩塌
- `dz > +LoD`：堆積
- `|dz| <= LoD`：低於偵測門檻，視為無顯著變化

實際崩塌面積、崩塌體積、最大崩落深度等統計直接來自 DoD；不需要先知道地下滑動面。

## 四、殘餘土體

殘餘土體不是單純的 `T1 - T2`。它需要一個滑動面假設。

等深度假設可用於基準情境與敏感度分析；DoD 幾何推估滑動面屬研究性方法；上傳滑動面則可使用外部高程／深度 raster。

沒有鑽孔、傾度管、地球物理或其他地工資料時，DoD 本身不能直接證明真正的地下滑動面深度。

## 五、V4 大檔穩定化

- 分析頁「降採樣倍率」預設 **4 倍**。
- 主入口與工作頁分離，使用者清楚依序操作。
- 殘餘土體採 **按鈕才計算**。
- 敏感度分析採 **按鈕才計算**。
- 等深度情境避免建立整張 slip/thickness raster。
- DoD 與大型分析結果使用 session cache，減少互動時重複讀檔。
- 大型研究性滑動面計算設有記憶體保護門檻。
- 建議大型資料優先使用前處理頁裁切／縮小。

## 七、本機執行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 八、Streamlit Cloud

Main file path：

```text
app.py
```

將整個專案內容放進 GitHub repository 後，Streamlit Community Cloud 指向該 repository 的 `app.py`。

## 九、工程使用提醒

本工具的 DoD 統計是地形表面變化分析。殘餘土體與滑動面部分屬假設／模型結果，不應在沒有地工調查資料時直接視為實際地下滑動面。正式工程判定仍應結合現地調查、鑽孔、地下水、監測與地質地工資料。
